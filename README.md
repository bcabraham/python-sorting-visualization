# python-sorting-visualization
https://en.wikipedia.org/wiki/Sorting_algorithm

## sorting algorithms
implement worst to best:
- bubble sort
- insertion sort
- comb sort
- selection sort
- quicksort
- heapsort
- merge sort
- tree sort
- timsort
- shellsort
- bucket sort
- radix sort (LSD/MSD)
- recombinant sort

## track stats:
- # of comparisons
- # of swaps or operations
- memory usage?
- list length
- time to complete

## tools:
- random number generator
- deterministic random generator that can generate lists with certain characteristics, like clumping

## tests:
- progressively larger lists
- a long reversed list
- non-unique values
